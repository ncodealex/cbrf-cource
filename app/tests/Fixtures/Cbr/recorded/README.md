# Записанные ответы ЦБ

15 календарных запросов за 12–26 октября 2026 года к `/scripts/XML_daily.asp`.
XML сохранён без перекодирования (windows-1251). `manifest.json` содержит URL,
дату действия из ответа и SHA-256 каждого файла. Соответствия дат получены
из ответов ЦБ, а не рассчитаны по выходным. В тестах внешних запросов нет.

Stub выбирает файл по `date_req` (`d/m/Y`); запрос без даты возвращает последний
записанный ответ (26 октября). Дата за пределами периода возвращает 404,
некорректная дата — 400. Старые XML в родительском каталоге остаются отдельными
синтетическими фикстурами Unit-тестов и не используются HTTP Stub.

`GET /health` проверяет HTTP-сервер, `GET /` возвращает счётчик запросов.
`POST /control` принимает `ok`, `503`, `invalid`, `delay` и сбрасывает счётчик.
Задержка — 3 секунды. Управление доступно только в изолированной тестовой сети.
